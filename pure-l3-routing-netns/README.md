# linux-networking-labs/pure-l3-routing-netns

This is an another minimalist project with simulating a multi-subnet virtual router 
from scrath using netns

 You can see topology below (generated by AI btw)

```
 [ Subnet A: 172.16.0.0/17 ]          [ Subnet B: 172.16.128.0/17 ]
 +-----------------+                    +-----------------+
 |     Host A      |                    |     Host B      |
 |  (Namespace 1)  |                    |  (Namespace 2)  |
 +--------+--------+                    +--------+--------+
   (veth-a1)  |                               |  (veth-b1)
              |                               |
              |     +------------------+      |
              |     |  Virtual Router  |      |
              |-----+  (Namespace 3)   |------+
         (veth-a2)  |                  |  (veth-b2)
                    +------------------+
```

Lab Stages
1. Phase 1: Network topology and L2 links
2. Phase 2: L3 Addressing and subnet design
3. Phase 3: Routing configuration
4. Phase 4: Verification and protocol analysis	

So, we can make sure that Host A never learns Host B's MAC address. Because
destination is in anpther subnet. Either Host A or B resolve thw MAC of its default
gateway to forward the frame. Also, we can see that TTL equal to 63,
the linux kernel decrements the TTL by 1
during the routing

You can see the photos and logs in ".images/" directory, also in the "router.log" file.
